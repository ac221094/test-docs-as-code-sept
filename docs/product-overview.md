# Product overview

BMC Project Planner, a cloud-based project management application, helps teams to plan, organize, track, and collaborate on projects from any location through a web browser or mobile device. It is designed for project managers, team members, business leaders, and organizations of all sizes that need to manage tasks and deliver projects efficiently. 

By centralizing project information in the cloud, the application enables teams to stay aligned, make informed decisions, and complete projects more effectively.

This application is available in two variants, basic and advanced. Use the variant that suits your business needs.
> [!TIP]
> To stay up-to-date with all the latest features, use the advanced variant.

## Application benefits
The application provides the following benefits:
- Improved collaboration
- Real-time visibility into project progress
- Streamlined communication
- Increased productivity

## Key capabilities
The application provides the following key capabilities:
- Modern yet easy ways to assign tasks and track them
- Manage schedules and milestones
- Allocate resources automatically
- Switch between mobile and desktop views using the **Device** option on the application home page
    > [!NOTE]
    > This capability is available only in version 2.0 of the application.
- Report progress using dashboards
